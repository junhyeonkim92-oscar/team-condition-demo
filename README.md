# 팀 컨디션 보드 (가칭)

운동부 지도자가 **선수들의 오늘 컨디션을 한 화면에서 확인**하는 코치용 대시보드입니다.
종목과 연령을 가리지 않습니다 — 실업팀(성인)부터 중·고 운동부(미성년)까지 같은 화면으로 운영합니다.

헤이제임스 8주 프로그램 **1주차 제출물** — 1차 프로젝트(축소판)의 첫 화면입니다.

**라이브 데모** → https://junhyeonkim92-oscar.github.io/team-condition-demo/

---

## 무엇을 해결하나

현장 지도자는 선수 컨디션을 카톡·구두·수첩으로 따로따로 받습니다.
누가 오늘 안 좋은지 알려면 대화방을 거슬러 올라가야 하고, 기록은 시즌이 끝나면 사라집니다.

그리고 **미성년 팀은 쓸 도구가 아예 없습니다.** 기존 서비스는 개인정보 동의 부담 때문에 성인만 받습니다.
정작 관리가 가장 필요한 쪽은 학생 선수입니다.

| | |
|---|---|
| 누가 | 팀 단위로 운영되는 모든 운동부의 지도자 — 실업·대학팀, 중·고 운동부, 종목별 육성팀 |
| 어떤 문제 | 컨디션 정보가 흩어져 기록으로 안 남고, 미성년 팀은 동의 부담 때문에 도구 자체가 없음 |
| 어떻게 | 선수 30초 자가입력 → 코치 대시보드에 신호로 정렬 + 법정대리인 동의 절차를 제품에 내장 |

## 화면에서 확인할 것

우측 상단 **팀 선택 드롭다운**으로 세 가지 운영 형태를 전환해 볼 수 있습니다.

| 팀 | 연령 | 동의 처리 |
|---|---|---|
| 봅슬레이·스켈레톤 실업팀 | 성인 12명 | 본인 동의 + 민감정보 별도 동의 |
| ○○고등학교 육상부 | U-18 · 18명 | 본인 동의 + 법정대리인 동의 |
| ○○중학교 수영부 | U-15 · 14명 | 법정대리인 동의 (만 14세 미만 6명 포함) |

- **오늘의 팀 현황** — 입력 완료 인원 / 컨디션 신호 / 통증 보고 / 팀 평균 훈련부하(ACWR)
- **동의 현황 배너** — 팀 연령 구성과 동의 완료 상태를 화면 최상단에 상시 노출
- **선수 로스터** — 신호 순 정렬, 선수별 연령 구분과 동의 상태 표시
- **입력률 추이** — 최근 14일 (자가입력 서비스의 생존 지표)

## 설계 원칙

1. **부상을 판정하지 않습니다.** 신호는 수면·피로도·통증·훈련부하의 *변화 폭*을 표시하는 모니터링 지표이며,
   최종 판단은 지도자·의무팀이 합니다.
2. **미성년을 배제하지 않고, 동의로 해결합니다.** 만 14세 미만은 법정대리인 동의 없이 계정이 생성되지 않고,
   동의·철회 이력이 자동 기록됩니다. 지도자가 종이 동의서를 걷지 않습니다.
3. **건강 관련 정보는 민감정보**로 분류해 별도 동의 후 수집하고, 국내 서버에 암호화 저장합니다.
4. **표시된 선수 정보는 전부 가명·예시값**입니다.

## 수익 모델

팀 단위 **월 구독**입니다. 선수·학부모에게는 과금하지 않습니다.

| 구간 | 금액 |
|---|---|
| 유소년·학교팀 (20명 이하) | 월 5.9만 원 · 연 결제 59만 원 |
| 실업·대학·클럽팀 (50명 이하) | 월 14.9만 원 · 연 결제 149만 원 |
| 연맹·시도체육회 (다팀) | 월 39만 원부터 |

지불 의사는 아직 검증 전입니다. 3주 파일럿에서 확인할 것은 "낼 의향이 있나"가 아니라 **어느 예산 항목에서 나가나**입니다.

## 3주 로드맵

| 주차 | 범위 |
|---|---|
| 1주차 | 화면 확정 · 데이터 모델 설계 · 배포 파이프라인 (**현재 지점**) |
| 2주차 | 로그인·권한분리 / 연령 확인 + 법정대리인 동의 절차 / 선수 입력 폼 + 저장 |
| 3주차 | 주간 리포트 PDF · 약관·처리방침·탈퇴 · 실팀 1곳 파일럿 투입 |

**이번에 만들지 않는 것** — 알림톡·푸시 자동 리마인드(채널 심사 대기), 웨어러블 자동연동,
스토어 배포, 결제·구독 자동화(PG 심사 2~4주). 전부 외부 승인이 걸려 3주를 약속할 수 없는 일입니다.

## 기술 스택

현재 화면은 의존성 없는 정적 HTML/CSS/JS 입니다.
2주차부터 서버·DB를 붙이며, 건강 관련 정보는 **국내 서버 저장 + 별도 동의** 전제로 설계합니다.
